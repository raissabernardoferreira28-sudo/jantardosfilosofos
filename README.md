# jantardosfilosofos
jantardosfilosofos
O clássico Problemas dos Filósofos Comilões é um modelo conceitual utilizado para estudar a sincronização de processos e a prevenção de impasses (deadlocks) em sistemas recorrentese. Nele, cinco filósofos (representados por Threads) estão sentados em uma mesa redonda, alternando entre pensar e comer; porém, para comer, cada um precisa de dois garfos (representados por Locks), sendo que cada garfo é compartilhado com o vizinho ao lado. O código implementa uma lógica de tentativa e desistência: cada filósofo só começa a comer se conseguir pegar os dois garfos (representados por Locks); caso o segundo garfo esteja ocupado, ele solta o primeiro e volta a pensar. A simulação utiliza tempos aleatórios para dar realismo e monitora o progresso através de uma lista que contabiliza as refeições de cada participante

# jantardosfilosofos
jantardosfilosofos
O clássico Problemas dos Filósofos Comilões é um modelo conceitual utilizado para estudar a sincronização de processos e a prevenção de impasses (deadlocks) em sistemas recorrentese. Nele, cinco filósofos (representados por Threads) estão sentados em uma mesa redonda, alternando entre pensar e comer; porém, para comer, cada um precisa de dois garfos (representados por Locks), sendo que cada garfo é compartilhado com o vizinho ao lado. A lógica central reside no método 'comer()', que utiliza uma estratégia de tentativa e erro para evitar que o sistema trave: o filósofo adquire o primeiro garfo de forma obrigatória, mas tenta adquirir o segundo de forma não bloqueante (garfo2.acquire(False)) caso o segundo esteja ocupado, ele imediatamente libera o primeiro e volta a pensar, impedindo que todos segurem um recurso e fiquem esperando eternamente pelo próximo (o que causaria um deadlock). O programa principal gerencia o ciclo de vida dessas threads através da variável global execute, contabilizando no array pratos quantas vezes cada filósofo conseguiu se alimentar com sucesso antes de encerrar a simulação.
